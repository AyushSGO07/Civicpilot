# Plan 08-02: Implement Bounded Error Recovery, Dialog Handlers, and Workflow API Endpoints

## Objective
Implement bounded error recovery in the LangGraph workflow with unexpected alert/popup handling, re-inspection, a strict 3-retry limit (`AGENT-06`), graceful transition to human assistance, and FastAPI endpoints to start, inspect, and resume workflows.

## Step-by-Step Implementation

### Step 1: Implement Recovery & Human Assistance Nodes
File: `backend/app/services/workflow_engine.py`
- Add:
  - `recovery_node(state)`:
    - Increments `state["error_count"]`.
    - Logs recovery attempt (e.g. "Attempt 1/3: Dismissing alerts, re-evaluating DOM...").
    - If `state["error_count"] <= state["max_retries"]`:
      - Clears transient errors, forces DOM re-inspection.
      - Returns updated state.
  - `human_assistance_node(state)`:
    - Sets `current_step = "human_assistance"`.
    - Logs escalation: "Exceeded max retries (3/3). Pausing automation for human assistance."
    - Preserves all error context, locators, and screenshot for human intervention.
  - Conditional edge routing `route_after_validation(state)`:
    - If `failed_actions > 0`:
      - If `error_count < max_retries`: return `"recovery"`
      - Else: return `"human_assistance"`
    - Else: return `"waiting_approval"` or `"completed"`
  - Conditional edge routing `route_after_recovery(state)`:
    - If `error_count >= max_retries`: return `"human_assistance"`
    - Else: return `"inspect"`
- Playwright Dialog Listener:
  - `page.on("dialog", handler)`:
    - Automatically records `dialog.message` into `state["dialog_messages"]`.
    - Accepts or dismisses the dialog safely to avoid blocking the event loop.

### Step 2: Implement FastAPI Workflow Router Endpoints
File: `backend/app/routers/agent.py`
- Endpoints:
  - `POST /api/agent/workflow/start`: Accepts `WorkflowStartRequest`, initializes state with `thread_id`, starts background or synchronous graph execution, returns `WorkflowStateResponse`.
  - `GET /api/agent/workflow/{thread_id}/state`: Retrieves the current state snapshot from the checkpointer.
  - `POST /api/agent/workflow/{thread_id}/resume`: Resumes execution on a paused thread (e.g. after human review).

### Step 3: Expand Pytest Suite in `test_agent_workflow.py`
- Test dialog listener: triggers `window.alert('Important Notice')`, verifies message captured and unblocked.
- Test bounded recovery: transient failure causes recovery node to retry once and succeed.
- Test 3-retry escalation: persistent error executes recovery 3 times, then transitions to `human_assistance` with `error_count == 3` (AGENT-06).
- Test FastAPI workflow endpoints (`/workflow/start`, `/workflow/{thread_id}/state`).
