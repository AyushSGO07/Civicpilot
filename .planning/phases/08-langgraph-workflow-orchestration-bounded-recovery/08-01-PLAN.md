# Plan 08-01: Construct LangGraph Agent Workflow State Graph and Execution Nodes

## Objective
Construct the core cyclical LangGraph state machine using `langgraph.graph.StateGraph` and `MemorySaver`. Define the workflow state schema and implement nodes for Discovery, Navigation, DOM Inspection, Dynamic Mapping, Form Population, and Post-Fill Validation.

## Step-by-Step Implementation

### Step 1: Create Workflow Schemas
File: `backend/app/models/workflow.py`
- Define:
  - `WorkflowStep = Literal["discovery", "navigation", "inspection", "mapping", "filling", "validation", "recovery", "waiting_approval", "human_assistance", "completed", "failed"]`
  - `AgentWorkflowState(TypedDict)`:
    - `session_id: str`
    - `thread_id: str`
    - `service_id: str`
    - `portal_url: str`
    - `citizen_profile: dict`
    - `vault_documents: list`
    - `current_step: WorkflowStep`
    - `dom_tree: Optional[dict]`
    - `fill_plan: Optional[dict]`
    - `execution_result: Optional[dict]`
    - `error_count: int`
    - `max_retries: int`
    - `error_message: Optional[str]`
    - `dialog_messages: List[str]`
    - `logs: List[dict]`
    - `screenshot_base64: Optional[str]`
  - Request/Response models:
    - `WorkflowStartRequest`: `service_id`, `custom_profile`, `portal_url_override`
    - `WorkflowStateResponse`: `thread_id`, `session_id`, `service_id`, `current_step`, `error_count`, `error_message`, `dialog_messages`, `logs`, `screenshot_base64`

### Step 2: Implement LangGraph State Graph & Nodes
File: `backend/app/services/workflow_engine.py`
- Implement node functions:
  - `discover_node(state)`: Resolves scheme details from catalog and determines target application URL.
  - `navigate_node(state)`: Initializes/reuses Playwright session, registers automated dialog handler, navigates to portal URL, captures screenshot.
  - `inspect_node(state)`: Runs `DOMInspector.inspect_page()` to produce `SanitizedDOMTree`.
  - `map_node(state)`: Runs `DynamicFieldMapper.generate_fill_plan()` to generate `FormFillPlan`.
  - `fill_node(state)`: Runs `FormActionExecutor.execute_plan()` to populate fields and attach documents.
  - `validate_node(state)`: Verifies actions, logs audit records, and checks whether any failed actions occurred.
- Build and compile graph with `MemorySaver` checkpointer:
  - Nodes: `discover`, `navigate`, `inspect`, `map`, `fill`, `validate`.
  - Compile into `agent_workflow_app`.

### Step 3: Implement Initial Tests
File: `backend/tests/test_agent_workflow.py`
- Test full graph compilation.
- Test happy-path execution traversing through all nodes.
- Test checkpoint persistence using `thread_id`.

## Verification
- Run `pytest backend/tests/test_agent_workflow.py -v`.
- Verify smooth node transitions and state updates.
