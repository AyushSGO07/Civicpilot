# Plan 09-01: Build FastAPI WebSocket Manager and Agent Execution Controller

## Objective
Implement the backend WebSocket streaming manager and execution controller. Streams real-time JSON milestone events, step progression, and Base64 visual frames to clients connected to `/ws/agent/{sessionId}`. Provides Pause, Resume, and Stop controls that synchronously manage the underlying Playwright browser session.

## Step-by-Step Implementation

### Step 1: Implement `AgentWebSocketManager`
File: `backend/app/services/websocket_manager.py`
- Methods:
  - `connect(session_id: str, websocket: WebSocket)`: Registers active connection.
  - `disconnect(session_id: str, websocket: WebSocket)`: Removes connection.
  - `broadcast_json(session_id: str, data: dict)`: Serializes and sends JSON frame to all session subscribers.
  - `broadcast_status(session_id: str, status: str, step: str)`: Emits status frame.
  - `broadcast_milestone(session_id: str, step: str, message: str, level: str = "info")`: Emits milestone log frame (EXEC-02).
  - `broadcast_screenshot(session_id: str, screenshot_b64: str)`: Emits visual buffer frame (EXEC-03).

### Step 2: Implement `SessionExecutionController`
File: `backend/app/services/execution_controller.py`
- Tracks session execution state:
  - `pause_event = asyncio.Event()` (set initially).
  - `stop_event = asyncio.Event()` (cleared initially).
  - `pause()`: Clears pause event, broadcasts status `paused` (EXEC-04).
  - `resume()`: Sets pause event, broadcasts status `resumed` (EXEC-04).
  - `stop()`: Sets stop event, closes browser session via `browser_manager.close_session()`, broadcasts status `stopped` (EXEC-05).
  - `check_gate()`: Awaits `pause_event.wait()` or raises `CancelledError` if stopped.

### Step 3: Implement WebSocket Endpoint
File: `backend/app/routers/websocket.py`
- Route `@router.websocket("/agent/{session_id}")`:
  - Accepts connection, emits handshake frame.
  - Listens for inbound control actions: `pause`, `resume`, `stop`, `start`.
  - Routes inbound actions to `execution_controller`.
  - Handles client disconnects cleanly.

### Step 4: Mount Router in `backend/app/main.py`
- Mount `websocket.router` at `/ws` (and `/api/ws` alias).

### Step 5: Implement Automated Pytest Suite
File: `backend/tests/test_agent_websocket.py`
- Test connection handshake.
- Test milestone and screenshot broadcasting.
- Test pause, resume, and stop control actions.

## Verification
- Run `pytest backend/tests/test_agent_websocket.py -v`.
- Verify real-time event streaming and pause/stop controls respond cleanly.
