# Plan 09-03: Implement Agent Execution Controls (Start, Pause, Resume, Stop)

## Objective
Wire the interactive control toolbar in the Center Viewport panel of the workspace, allowing the citizen to Pause, Resume, or Abort execution at any time. Sends control actions over WebSocket and HTTP to the backend execution controller, synchronously freezing or terminating the Playwright browser.

## Step-by-Step Implementation

### Step 1: Implement Interactive Control Toolbar
File: `frontend/app/applications/workspace/[sessionId]/page.tsx`
- Controls:
  - **Start Execution** (if in idle state): sends `{"action": "start"}` to launch workflow.
  - **Pause Execution** (when active):
    - Sends `{"action": "pause"}`.
    - Viewport dims with amber overlay: "Execution Paused by Citizen".
    - Button toggles to **Resume Execution** (Civic Blue) (EXEC-04).
  - **Resume Execution** (when paused):
    - Sends `{"action": "resume"}`.
    - Viewport clears overlay, resumes live streaming (EXEC-04).
  - **Abort / Stop Execution** (any time):
    - Red button with confirmation dialog.
    - Sends `{"action": "stop"}`.
    - Backend terminates Playwright session and context cleanly (EXEC-05).
    - Viewport displays "Execution Terminated Safely".

### Step 2: Keyboard Shortcuts & Accessibility
- Spacebar: Toggle Pause/Resume.
- Escape: Abort execution safely.
- ARIA live announcements for screen readers on state changes.

### Step 3: Frontend Build & End-to-End Verification
- Run `npm --prefix frontend run build` to verify clean compilation.
- Verify controls over WebSocket protocol.

## Verification
- Clicking Pause halts backend execution without closing the browser.
- Clicking Resume unblocks execution immediately.
- Clicking Stop shuts down Chromium context and returns status `stopped`.
