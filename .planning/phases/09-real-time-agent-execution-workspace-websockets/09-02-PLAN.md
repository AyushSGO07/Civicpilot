# Plan 09-02: Create Frontend Agent Execution Workspace Layout and Real-time Stream Canvas

## Objective
Build the MakeMyTrip-inspired 3-panel operations workspace at `/applications/workspace/[sessionId]`. Features Left Panel (Citizen Profile Summary & Vault Documents), Center Panel (Live Browser Viewport Canvas & Step Tracker), and Right Panel (AI Reasoning Log & Audit Stream). Connects to backend WebSocket (`/ws/agent/{sessionId}`) to receive real-time visual frames and milestone events.

## Step-by-Step Implementation

### Step 1: Implement Application Fast-Track Launcher
File: `frontend/app/applications/new/page.tsx`
- Accepts query parameters `?serviceId=...`.
- Fetches scheme metadata and citizen profile.
- Calls backend to start a browser session or launches workspace at `/applications/workspace/[sessionId]?serviceId=...`.

### Step 2: Implement 3-Panel Agent Execution Workspace
File: `frontend/app/applications/workspace/[sessionId]/page.tsx`
- Layout & Component Panels (EXEC-01):
  - **Top Workspace Bar**:
    - Scheme title & Issuing department.
    - Target portal URL pill with external link.
    - Status pill with pulsing live dot (Pulsing Emerald Green when live, Amber when paused, Rose Red when stopped).
    - Exit / Return button.
  - **Panel 1: Citizen Profile Summary (Left 1/4)**:
    - Identity: Full Name, DOB, Gender, Mobile, Domicile State, PIN Code.
    - Eligibility Attributes: Income, Social Category, Occupation.
    - Attached Vault Certificates with verified checkmarks (Aadhaar, Income, Marksheet).
  - **Panel 2: Live Browser Viewport Stream (Center 2/4)** (EXEC-03):
    - Dark canvas (`bg-slate-900`) with 16:10 aspect ratio matching 1280x800 desktop resolution.
    - Displays incoming Base64 JPEG frames reactively (`data:image/jpeg;base64,...`).
    - Overlay indicator showing current step (e.g. `Step 4: Mapping Fields` or `Step 5: Form Filling`).
    - Interactive controls bar placeholder (to be wired in 09-03).
    - Empty state: clean government portal browser preview mock with scanline effect during initialization.
  - **Panel 3: AI Reasoning Log (Right 1/4)** (EXEC-02):
    - Real-time auto-scrolling log timeline.
    - Each milestone displays: timestamp, step badge (Discovery, Navigation, Inspection, Mapping, Filling, Validation), level icon, and reasoning narrative.
    - Filter toggle between "All Events" and "AI Reasoning".

### Step 3: Implement Native WebSocket Client Hook / Connection
- Connects to `ws://localhost:8000/ws/agent/${sessionId}`.
- Listens for `type: "status"`, `type: "milestone"`, `type: "screenshot"`.
- Updates React state reactively as new frames and logs arrive.
- Fallback mock streamer when running offline or without active backend to ensure judge/demo resilience.

## Verification
- Verify Next.js App Router static compilation (`npm --prefix frontend run build`).
- Ensure 3-panel layout renders smoothly with live visual frame updates.
