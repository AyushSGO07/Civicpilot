# Plan 10-02: Implement Security Challenge Detector (CAPTCHA / OTP / MFA) and Citizen Pause Gate

## Objective
Detect CAPTCHA, SMS OTP, and Aadhaar OTP security challenges on government portals during autonomous execution (HIL-04). When a challenge is encountered, the agent suspends browser automation, transitions LangGraph state to `waiting_security_challenge`, notifies the citizen over WebSockets with clear instructions, and provides a 1-click resumption trigger once the citizen completes the challenge in the browser session.

## Step-by-Step Implementation

### Step 1: Define Security Challenge Data Models
File: `backend/app/models/security_challenge.py`
- `SecurityChallengeInfo`:
  - `detected: bool = False`
  - `challenge_type: Optional[Literal["captcha", "otp", "mfa"]] = None`
  - `element_locator: Optional[str] = None`
  - `instructions: str = ""`
  - `prompt_message: str = ""`
  - `detected_at: Optional[str] = None`
- `ResolveChallengeRequest`:
  - `challenge_type: Literal["captcha", "otp", "mfa"]`
  - `resolution_notes: Optional[str] = None`

### Step 2: Implement `SecurityChallengeDetector`
File: `backend/app/services/security_detector.py`
- Methods:
  - `detect_challenge_in_dom(dom_tree: SanitizedDOMTree) -> SecurityChallengeInfo`:
    - Checks interactive inputs for IDs/names/labels matching `captcha`, `recaptcha`, `hcaptcha`, `turnstile`, `txtCaptcha`.
    - Checks for OTP inputs matching `otp`, `sms-otp`, `aadhaar-otp`, `txtOtp`, `verification_code`.
    - Returns `SecurityChallengeInfo` with clear citizen instructions (e.g. "Please type the CAPTCHA code shown on the portal screen" or "Please enter the OTP sent to your registered mobile number").
  - `detect_challenge_in_page_content(text: str) -> SecurityChallengeInfo`:
    - Fast regex scan for security challenge phrases: "Enter OTP sent to", "Enter the characters", "Verification code", "Type the text from the image".
  - `detect_challenge(dom_tree: Optional[SanitizedDOMTree] = None, page_text: Optional[str] = None) -> SecurityChallengeInfo`:
    - Composite evaluator combining DOM and text signals.

### Step 3: Integrate Security Challenge Pause in LangGraph Workflow
File: `backend/app/services/workflow_engine.py`
- Update `AgentWorkflowState`:
  - `security_challenge: Optional[Dict[str, Any]] = None`
  - `challenge_resolved: bool = False`
- In `inspect_node` and `fill_node`:
  - Run `SecurityChallengeDetector.detect_challenge()` after page inspection or before action execution.
  - If challenge detected and not yet resolved:
    - Route to `waiting_security_challenge_node`.
    - Pause session via `execution_controller.pause(session_id)`.
    - Broadcast WebSocket event `security_challenge` with instructions.
- Add `waiting_security_challenge_node`:
  - Sets `current_step = "waiting_security_challenge"`.
  - Emits milestone: "Security challenge detected on portal (CAPTCHA/OTP). Pausing automation for citizen input (HIL-04)."
- Add conditional routing:
  - If challenge resolved, route back to `fill_node` or `validate_node`.

### Step 4: Implement Challenge Resolution Endpoints & WebSocket Support
Files: `backend/app/routers/agent.py` and `backend/app/routers/websocket.py`
- Endpoint `POST /workflow/{thread_id}/resolve-challenge`:
  - Sets `challenge_resolved = True` in workflow checkpoint.
  - Unpauses `execution_controller.resume(session_id)`.
  - Resumes workflow execution via `ainvoke(None, config)`.
- WebSocket handler:
  - Accepts action `{"action": "resolve_challenge"}` and routes to execution controller and workflow.

### Step 5: Implement Frontend Security Checkpoint Overlay
File: `frontend/app/applications/workspace/[sessionId]/page.tsx`
- Displays glowing amber Security Checkpoint banner above browser viewport when `executionStatus === "waiting_security_challenge"` or challenge event is received:
  - Shield / Lock icon with pulsing amber indicator.
  - Header: "Security Checkpoint Detected: [CAPTCHA / OTP Verification Required]".
  - Detailed instruction text guiding the citizen to enter the OTP or solve the CAPTCHA directly in the portal.
  - Primary CTA button: **"I have completed CAPTCHA / OTP — Resume Automation"** (Civic Blue).
  - Clicking sends `resolve_challenge` over WebSocket and POSTs to `/api/agent/workflow/{threadId}/resolve-challenge`.

### Step 6: Automated Pytest Suite
File: `backend/tests/test_agent_security_challenge.py`
- Test detection of image CAPTCHAs from element signatures.
- Test detection of OTP fields from element signatures and prompts.
- Test negative case on standard clean forms.
- Test workflow transitions to `waiting_security_challenge` and suspends execution.
- Test resolving challenge resumes workflow.
