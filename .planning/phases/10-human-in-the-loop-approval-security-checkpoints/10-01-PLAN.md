# Plan 10-01: Implement Pre-Submission Summary Payload, Approval State Machine, and Review Modal

## Objective
Enforce mandatory citizen consent before application submission. The LangGraph agent pauses execution after validating form inputs and compiles a structured `PreSubmissionSummary` containing all populated form fields and attached vault documents (HIL-01, HIL-02). Provides backend endpoints and a frontend modal in the MakeMyTrip operations workspace enabling the citizen to review the data and explicitly approve or reject submission (HIL-03).

## Step-by-Step Implementation

### Step 1: Define Pre-Submission Summary and Approval Data Models
File: `backend/app/models/approval.py`
- `PopulatedFormField`: `field_label`, `element_name`, `locator`, `value_populated`, `source_attribute`, `confidence`.
- `AttachedVaultDocument`: `document_name`, `document_type`, `vault_id`, `verified`.
- `PreSubmissionSummary`:
  - `service_id: str`, `service_name: str`, `portal_url: str`
  - `populated_fields: List[PopulatedFormField]`
  - `attached_documents: List[AttachedVaultDocument]`
  - `generated_at: str`, `total_fields: int`, `all_mandatory_satisfied: bool`
  - `disclaimer: str`
- `ApprovalDecisionRequest`: `decision: Literal["approved", "rejected"]`, `rejection_reason: Optional[str] = None`.
- `ApprovalDecisionResponse`: `thread_id: str`, `status: str`, `decision: str`, `message: str`.

### Step 2: Update LangGraph Workflow Engine for Approval Pause Gate
File: `backend/app/services/workflow_engine.py`
- Update `AgentWorkflowState`:
  - `pre_submission_summary: Optional[Dict[str, Any]]`
  - `approval_decision: Optional[str]`
  - `rejection_reason: Optional[str]`
- In `waiting_approval_node`:
  - Extract mapped actions from `fill_plan` and successful results from `execution_result`.
  - Assemble `PreSubmissionSummary` instance and persist in `state["pre_submission_summary"]`.
  - Emit milestone: "Pre-submission summary compiled. Pausing automation for citizen authorization (HIL-01)."
- Add `submit_node`:
  - Transitions `current_step = "submission_ready"` (submission execution in Phase 11).
  - Emits milestone: "Citizen approved application submission. Proceeding with portal submission."
- Add `rejected_node`:
  - Transitions `current_step = "submission_rejected"`.
  - Emits milestone: "Citizen rejected application submission. Returning to review mode."
- Conditional Routing `route_after_approval`:
  - If `approval_decision == "approved"` -> `submit_node`.
  - If `approval_decision == "rejected"` -> `rejected_node`.
  - Otherwise -> stays in `waiting_approval`.

### Step 3: Implement Backend Approval API Endpoints
File: `backend/app/routers/agent.py`
- `GET /workflow/{thread_id}/summary`:
  - Retrieves persisted `PreSubmissionSummary` from checkpoint snapshot.
- `POST /workflow/{thread_id}/approve`:
  - Sets `approval_decision = "approved"`, resumes workflow via `ainvoke(None, config)`, returns updated state.
- `POST /workflow/{thread_id}/reject`:
  - Sets `approval_decision = "rejected"` and `rejection_reason`, updates workflow state, returns updated state.

### Step 4: Implement Frontend Pre-Submission Review Modal
File: `frontend/app/applications/workspace/[sessionId]/page.tsx`
- Triggers modal when `executionStatus === "waiting_approval"` or via dedicated "Review & Submit" CTA.
- MakeMyTrip high-contrast modal:
  - Header: Scheme name, portal domain pill, total fields count badge.
  - Section 1: Form Fields Review table with field name, input value, source citizen attribute, and confidence pill.
  - Section 2: Attached Vault Documents cards with verified checkmark badges.
  - Section 3: Statutory Advisory Disclaimer banner: "Explicit Citizen Consent Required: Please verify all entered details before granting final submission authority."
  - Action buttons:
    - **"Approve & Submit Application"** (Emerald / Civic Blue with ShieldCheck icon).
    - **"Reject / Edit Details"** (Outline with RotateCcw icon).
- Handles API call to `/api/agent/workflow/{threadId}/approve` or `/reject` and WebSocket message.

### Step 5: Automated Pytest Suite
File: `backend/tests/test_agent_approval.py`
- Test summary compilation with populated fields and attached vault docs.
- Test workflow stops at `waiting_approval` without continuing.
- Test approval endpoint triggers progression to submission ready.
- Test rejection endpoint records rejection and halts submission.
- Test summary GET endpoint returns 200 OK with valid schema.
