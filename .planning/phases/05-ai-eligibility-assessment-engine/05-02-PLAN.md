# Plan 05-02: Build MakeMyTrip Scheme Detail and AI Eligibility Assessment UI

## Objective
Build the citizen-facing Scheme Detail and AI Eligibility Assessment page at `/services/[serviceId]/page.tsx`, providing instant automated evaluation, status banner with color-coded classification, itemized criteria comparison matrix, missing profile attributes alert with direct links to `/profile`, required document checklist, official disclaimer, and links to explore or launch execution.

## Step-by-Step Implementation

### Step 1: Create Scheme Detail and AI Eligibility Assessment Page
File: `frontend/app/services/[serviceId]/page.tsx`
- Layout & Design:
  - Breadcrumb navigation: `Explore Services / {Category} / {Scheme Name}`.
  - Header Banner:
    - Official scheme title and issuing Ministry/Department.
    - Badges: Category pill, State / Central pill, Application deadline pill.
    - External link button: "Official Portal Guidelines" with `ExternalLink` icon and `target="_blank" rel="noopener noreferrer"`.
  - Main Grid (2-column layout on desktop, stacked on mobile):
    - Left Column (2/3 width):
      - **AI Eligibility Assessment Card**:
        - "AI Eligibility Assessment" badge with Sparkles icon.
        - Primary status badge:
          - `Likely Eligible` (emerald green badge, CheckCircle2)
          - `Likely Ineligible` (rose red badge, XCircle)
          - `More Information Required` (amber badge, AlertCircle)
        - AI Confidence score badge.
        - Comprehensive summary explaining evaluation logic.
        - **Missing Information Banner** (shown if `missing_fields.length > 0`):
          - Lists missing profile fields (e.g., Annual Income, Category).
          - Button: "Complete in Profile ->" linking to `/profile`.
        - **Itemized Criteria Comparison Table / Matrix**:
          - Header: Criterion & Condition | Your Profile Data | Status & Citation
          - Rows showing each condition evaluated, citizen's actual value, status badge (`Satisfied`, `Not Satisfied`, `Missing Info`), reasoning, and official citation pill.
      - **About the Scheme & Benefits Card**:
        - Full description and eligibility summary.
      - **Mandatory Documents Checklist**:
        - List of required documents with document vault status check ("Available in Vault" or "Upload Required" linking to `/documents`).
      - **Statutory Advisory Disclaimer Card**:
        - Prominent legal advisory text indicating final legal determination belongs to the issuing government authority.
    - Right Column (1/3 width):
      - **Action Fast-Track Card**:
        - Primary Action: "Apply with CivicPilot AI" (prepared for Phase 6-9 execution workspace).
        - Secondary Action: "Direct Apply on Portal" linking to official application URL.
      - **Scheme Snapshot Card**:
        - Key facts: Department, Level (Central/State), Deadline, Eligibility rule summary.

### Step 2: Update Services List Page to Link to Detail Page
File: `frontend/app/services/page.tsx`
- Ensure each scheme card's "Check Eligibility" button links directly to `/services/${service.id}`.

### Step 3: Frontend Build & Typecheck Verification
- Run `npm --prefix frontend run build` to verify Next.js App Router dynamic route compiles cleanly with zero warnings or errors.

## Verification
- Page `/services/[serviceId]` loads scheme details.
- Evaluation triggers automatically on load or via interactive button.
- Status badge renders properly (`Likely Eligible`, `Likely Ineligible`, `More Information Required`).
- Missing profile attributes alert displays clickable links to `/profile`.
- Criteria comparison matrix displays conditions, actual values, and official citations.
- Disclaimer is visible.
- Next.js build succeeds with 0 errors.
