# Plan 01-03: FastAPI Modular Backend Setup & Health Check Endpoint

<objective>
Initialize the modular FastAPI backend application under `backend/app/` with Pydantic settings, CORS middleware permitting `http://localhost:3000`, a verified `GET /api/health` endpoint, and automated pytest suite.
</objective>

</threat_model>

<action>
Implement the modular FastAPI backend application:
1. `backend/app/config.py`:
   - Create `Settings(BaseSettings)` with `PROJECT_NAME="CivicPilot API"`, `VERSION="1.0.0"`, `CORS_ORIGINS=["http://localhost:3000", "http://127.0.0.1:3000"]`.
   - Export `settings = Settings()`.
2. `backend/app/routers/health.py`:
   - Define Pydantic `HealthResponse(BaseModel)` with fields `status: str`, `service: str`, `version: str`.
   - Implement `GET /health` returning `HealthResponse(status="ok", service="CivicPilot API", version=settings.VERSION)`.
3. `backend/app/main.py`:
   - Instantiate `FastAPI` application with title and version.
   - Add `CORSMiddleware` using `settings.CORS_ORIGINS`.
   - Mount `health.router` under prefix `/api`.
</action>

</acceptance_criteria>
