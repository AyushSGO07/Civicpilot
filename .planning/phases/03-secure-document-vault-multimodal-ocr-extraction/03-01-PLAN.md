# Plan 03-01: Document Database Schema, Storage Engine & FastAPI Document Endpoints

<objective>
Define the PostgreSQL schema for citizen documents with Row Level Security (D-02: Document Database Schema & RLS), implement private storage handling with signed URL generation (D-01: Document Storage & Security), and create modular FastAPI document endpoints for upload, listing, download, and deletion with automated tests (D-03: FastAPI Document Endpoints).
</objective>

<execution_context>
- specs.md §3.4 (Document Vault) & §9 (Database Design)
- .planning/phases/03-secure-document-vault-multimodal-ocr-extraction/03-CONTEXT.md (D-01, D-02, D-03)
- .planning/phases/03-secure-document-vault-multimodal-ocr-extraction/03-RESEARCH.md (Database Schema & FastAPI UploadFile)
- .planning/phases/03-secure-document-vault-multimodal-ocr-extraction/03-VALIDATION.md (Pytest configuration)
</execution_context>

<threat_model>
ASVS Level 1:
- Never expose raw document files through unauthenticated public URLs.
- Restrict all document access, retrieval, and mutation strictly to the owning citizen using RLS (`auth.uid() = user_id`) and token authentication.
- Validate file MIME types (`application/pdf`, `image/jpeg`, `image/png`) and reject files exceeding 10MB to prevent storage abuse.
</threat_model>

- Columns: `id`, `user_id`, `document_name`, `document_type`, `mime_type`, `file_size_bytes`, `storage_path`, `extracted_information` (JSONB), `verification_status`, `created_at`, `updated_at`.

- Verification statuses: Unverified, Extracted, Verified, Rejected.
- Row Level Security (RLS) policies allowing users to SELECT, INSERT, UPDATE, and DELETE only their own documents (`auth.uid() = user_id`).

- backend/app/main.py
- .planning/phases/03-secure-document-vault-multimodal-ocr-extraction/03-RESEARCH.md

<action>
1. Add `python-multipart>=0.0.12` to `backend/requirements.txt` and install it.
2. Create `backend/app/models/document.py` with Pydantic schemas:
   - `DocumentBase`: Common document metadata.
   - `DocumentResponse`: Full schema including `id`, `user_id`, `document_name`, `document_type`, `mime_type`, `file_size_bytes`, `storage_path`, `download_url`, `verification_status`, `extracted_information`, `created_at`.
3. Create `backend/app/routers/documents.py`:
   - `POST /api/documents/upload`: Accepts `UploadFile` (validates MIME: PDF, JPEG, PNG, size <= 10MB) and `document_type`. Saves to private storage directory/bucket and creates document record.
   - `GET /api/documents`: Returns list of uploaded documents for authenticated citizen.
   - `GET /api/documents/{doc_id}`: Retrieves document details and temporary signed URL (or stream).
   - `DELETE /api/documents/{doc_id}`: Deletes file from private storage and deletes metadata record (DOC-05).
4. Register `documents.router` in `backend/app/main.py` under `settings.API_PREFIX`.
</action>

</acceptance_criteria>
