# Plan 12-01: Conduct End-to-End Workflow Testing Against Target Official Portals with Error Scenario Verification

## Objective
Implement an automated end-to-end integration test suite exercising the complete citizen lifecycle from Scheme Discovery through AI Eligibility, Document Vault, Playwright DOM mapping, LangGraph stateful execution, Human-in-the-Loop approval, Submission Verification, and PDF Receipt Download, while validating all edge cases and error recovery bounds.

## Step-by-Step Implementation

### Step 1: Create Comprehensive E2E Integration Suite
File: `backend/tests/test_e2e_integration.py`
- **Test 1: Full Happy-Path Lifecycle (`test_e2e_happy_path_lifecycle`)**:
  - Step 1: Discovery (`GET /api/services?q=scholarship`) finds genuine Post-Matric Scholarship scheme.
  - Step 2: AI Eligibility (`POST /api/eligibility/evaluate`) verifies citizen eligibility with high confidence (>0.85) and guideline citation.
  - Step 3: Profile & Vault (`GET /api/profile`, `GET /api/documents`) verifies citizen profile and verified certificates.
  - Step 4: Stateful Workflow Initiation (`POST /api/agent/workflow/start`) executes through discovery, navigation, inspection, mapping, filling, and validation to reach `waiting_approval`.
  - Step 5: Pre-Submission Audit (`GET /api/agent/workflow/{thread_id}/summary`) returns populated form values, attached vault documents, and statutory advisory disclaimer (`HIL-01`, `HIL-02`).
  - Step 6: Explicit Citizen Approval (`POST /api/agent/workflow/{thread_id}/approve`) authorizes portal submission (`HIL-03`).
  - Step 7: Submission Verification & Reference Extraction (`APP-01`): workflow extracts authentic reference number (e.g. `NSP2026/APPL/894125`) and transitions to `submitted`.
  - Step 8: PDF Receipt Retrieval (`APP-02`, `APP-05`): calls `GET /api/applications/{app_id}/receipt`, streams valid PDF with `%PDF-` header and attachment filename.
  - Step 9: Applications Tracking Sync (`APP-03`, `APP-04`): calls `GET /api/applications`, confirms status `submitted`, reference number, and portal URL.

- **Test 2: Ineligible Citizen Handling (`test_e2e_ineligible_citizen_handling`)**:
  - Citizen with income exceeding scheme ceiling (e.g. ₹3,50,000 for Post-Matric SC).
  - Evaluates eligibility: `is_eligible=False`, confidence > 0.85, official guideline cited, statutory advisory included (`ELIG-01`, `ELIG-02`, `ELIG-04`).
  - Confirms system does not attempt futile application execution on government portal.

- **Test 3: Missing Information Alert (`test_e2e_missing_information_alert`)**:
  - Profile with empty domicile or caste attributes evaluated.
  - System flags missing criteria and returns clear guidance on missing vault documents (`ELIG-03`).

- **Test 4: Security Checkpoint Pause & Resume (`test_e2e_security_checkpoint_flow`)**:
  - Intercepts security challenge (CAPTCHA / OTP) during DOM inspection (`HIL-04`).
  - Automation pauses cleanly at `waiting_security_challenge`.
  - Resolves via `POST /api/agent/workflow/{thread_id}/resolve-challenge`.
  - Resumes execution towards mapping and filling.

- **Test 5: Citizen Rejection Gate (`test_e2e_citizen_rejection_at_gate`)**:
  - At `waiting_approval`, citizen submits `POST /api/agent/workflow/{thread_id}/reject` with revision notes (`HIL-03`).
  - Workflow transitions to `submission_rejected` and halts. Zero data submitted to portal.

- **Test 6: Bounded Recovery Escalation (`test_e2e_bounded_recovery_escalation`)**:
  - Simulates form field error loop in LangGraph.
  - Verifies bounded retry logic: retries up to 3 times before escalating cleanly to `human_assistance` (`AGENT-06`).
  - No infinite loops or resource exhaustion.

- **Test 7: PDF Receipt Integrity & SHA-256 Seal (`test_e2e_receipt_pdf_integrity`)**:
  - Direct audit of synthesized PDF: verified using PyMuPDF for document structure, Ashoka header, reference number, and SHA-256 seal.

### Step 2: Execute Test Suite and Verify Regressions
- Run `python -m pytest backend/tests/test_e2e_integration.py -v`.
- Run full regression: `python -m pytest backend/tests/ -v`.
- Ensure 100% of all tests pass.
