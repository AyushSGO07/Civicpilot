# Plan 11-01: Implement Portal Submission Verification, Acknowledgement Parsing, and Receipt Download Pipeline

## Objective
Implement backend capabilities to verify genuine portal submissions, parse authentic application acknowledgement reference numbers from confirmation pages/DOM (APP-01), generate and store official submission receipt PDFs (APP-02), and expose streaming download endpoints (APP-05).

## Step-by-Step Implementation

### Step 1: Define Application Data Models
File: `backend/app/models/application.py`
- `ApplicationStatus`: Literal["draft", "in_progress", "waiting_approval", "submitted", "approved", "rejected", "failed"].
- `ApplicationRecord`:
  - `id: str`, `user_id: str`, `service_id: str`, `service_name: str`, `department: str`, `category: str`
  - `portal_url: str`, `status: ApplicationStatus`
  - `acknowledgement_number: Optional[str] = None`
  - `confirmation_text: Optional[str] = None`
  - `submission_timestamp: Optional[datetime] = None`
  - `receipt_url: Optional[str] = None`
  - `receipt_path: Optional[str] = None`
  - `populated_data: Dict[str, Any]`
  - `created_at: datetime`, `updated_at: datetime`
- `SubmissionVerificationResult`:
  - `is_success: bool`, `acknowledgement_number: Optional[str]`, `confirmation_text: Optional[str]`, `submission_timestamp: Optional[datetime]`, `receipt_filename: Optional[str]`, `receipt_bytes: Optional[bytes]`
- `CreateApplicationRequest` & `UpdateApplicationRequest`.

### Step 2: Implement Submission Verifier & Receipt Generator
File: `backend/app/services/submission_verifier.py`
- `SubmissionVerifier`:
  - `extract_acknowledgement_number(text: str, dom_tree: Optional[SanitizedDOMTree] = None) -> Optional[str]`:
    - Regex pattern matching: `(?:Application|Acknowledgement|Reference|Registration|Token)\s*(?:No|Number|ID|#)?[:.\s]+([A-Z0-9\-_/]{6,32})`.
    - Normalizes string and strips trailing punctuation.
  - `verify_confirmation(text: str) -> bool`:
    - Checks for official success phrases ("submitted successfully", "application registered", "acknowledgement generated").
  - `async verify_submission(page, session_id: str, service_id: str) -> SubmissionVerificationResult`:
    - Interacts with Playwright page post-submit, captures page text and screenshot, parses reference number, and triggers receipt creation.
- `ReceiptGenerator`:
  - `generate_receipt_pdf(application: ApplicationRecord, profile: CitizenProfileBase) -> bytes`:
    - Produces authentic Government of India formatted PDF acknowledgement slip with Ashoka Lion emblem header, scheme metadata, reference number, citizen attributes, attached vault certificates, and SHA-256 digital verification seal.
  - `save_receipt_file(application_id: str, receipt_bytes: bytes) -> str`:
    - Stores file in `storage/receipts/{application_id}_receipt.pdf` and returns path.

### Step 3: Implement Applications Router & Receipt Download Endpoint
File: `backend/app/routers/applications.py`
- Endpoints:
  - `GET /api/applications`: Lists all applications for citizen with optional status filtering.
  - `GET /api/applications/{id}`: Retrieves single application record.
  - `POST /api/applications`: Creates or updates application record.
  - `GET /api/applications/{id}/receipt`: Streams the PDF receipt file with `Content-Disposition: attachment; filename="CivicPilot_Receipt_{ack_no}.pdf"` (APP-05).
- In-memory fallback repository `_APPLICATIONS_STORE` for deterministic testing and offline resilience.

### Step 4: Mount Applications Router & Update Workflow Engine
- Mount `applications.router` in `backend/app/main.py`.
- Update `submit_node` in `backend/app/services/workflow_engine.py`:
  - Runs submission verification via `SubmissionVerifier.verify_submission()`.
  - Captures acknowledgement number (`APP-01`).
  - Generates and saves receipt PDF (`APP-02`).
  - Updates application record status to `submitted`.
  - Transitions `current_step = "completed"` with acknowledgement number and receipt link.

### Step 5: Implement Automated Pytest Suite
File: `backend/tests/test_submission_and_applications.py`
- Test reference number regex extraction across varied portal patterns.
- Test submission confirmation verification.
- Test PDF receipt generation and byte header validity.
- Test `GET /api/applications` and `GET /api/applications/{id}/receipt`.
- Test LangGraph workflow submission integration.
