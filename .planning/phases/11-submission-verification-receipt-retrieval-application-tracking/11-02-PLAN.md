# Plan 11-02: Build 'My Applications' Dashboard and Post-Submission Tracking Experience

## Objective
Deliver the citizen-facing "My Applications" tracking dashboard at `/applications` following MakeMyTrip-inspired visual hierarchy (APP-03), displaying real-time status badges, authentic timestamps, official portal links, and reference numbers (APP-04), with 1-click receipt PDF download (APP-05). Additionally, elevate the Agent Workspace post-submission screen to provide immediate verification and direct links to the receipt and dashboard.

## Step-by-Step Implementation

### Step 1: Create the "My Applications" Dashboard Page
File: `frontend/app/applications/page.tsx`
- **Layout & Design System:**
  - MakeMyTrip elevated navy (`#1A2B4C`) hero banner with breadcrumbs and civic badge.
  - Header: "My Public Service Applications" with subtitle: "Track live status, reference numbers, and download official government submission receipts."
  - Metrics Cards Grid:
    - Total Applications (Count)
    - Submitted to Official Portals (Count, Emerald badge)
    - Under Citizen Review / Approval (Count, Amber badge)
    - Active / In Progress Workflows (Count, Blue badge)
  - Interactive Filter & Search Bar:
    - Search input (filter by scheme name, department, or acknowledgement reference number).
    - Category & Status filter tabs: `All`, `Submitted`, `Waiting Approval`, `In Progress`, `Draft`.
  - Application Cards Deck (`APP-03`, `APP-04`):
    - Scheme title & issuing ministry badge (Ministry of Social Justice, Ministry of Agriculture, NHA, etc.).
    - Scheme category pill (`Education`, `Healthcare`, `Agriculture`, `Social Welfare`).
    - Live Status Badge (`submitted` = Emerald "Official Submission Confirmed", `waiting_approval` = Amber "Waiting Citizen Approval", `in_progress` = Blue "Automating Form", `draft` = Slate "Draft Prepared").
    - Prominent Reference Number badge with 1-click copy button and visual "Copied!" notification (`APP-01`, `APP-04`).
    - Submission Timestamp formatted in Indian locale (e.g. `01 Nov 2026, 08:30 PM IST`) (`APP-04`).
    - Official Government Portal URL button with external link icon pointing to verified `.gov.in` domain (`APP-04`).
    - "Download Official Receipt (PDF)" action button calling `GET /api/applications/{id}/receipt` or fallback generator (`APP-05`).
    - "Open Operations Room" CTA button linking back to `/applications/workspace/{sessionId}`.
  - Empty State & Fallbacks:
    - Clean empty state with search reset button or "Explore Government Schemes" CTA button navigating to `/services`.
    - Resilient offline fallback dataset showcasing genuine schemes if backend is offline.

### Step 2: Elevate Agent Execution Workspace Post-Submission Screen
File: `frontend/app/applications/workspace/[sessionId]/page.tsx`
- Update `handleApproveSubmission` and simulation flow:
  - Once citizen grants approval, execute submission verification and extract authentic acknowledgement number (e.g. `NSP2026/APPL/894125`).
  - Add execution milestones for submission confirmation, reference extraction, and receipt generation.
  - Set state `submissionSuccessData` with reference number, timestamp, and receipt filename.
- Add Post-Submission Success Card / Banner in workspace:
  - Elevated card with emerald gradient and verified shield icon.
  - Displays: "Official Application Successfully Submitted & Verified".
  - Copyable Acknowledgement Reference Number badge.
  - Submission timestamp and digital seal info.
  - Two prominent action buttons:
    1. "Download Official Receipt (PDF)" calling receipt download.
    2. "View in My Applications" navigating directly to `/applications`.

### Step 3: Verify Frontend Compilation
- Run `npm --prefix frontend run build`.
- Ensure all routes (`/applications`, `/applications/workspace/[sessionId]`, `/applications/new`, etc.) compile cleanly with 0 TypeScript errors.

## Verification
- Visit `/applications` and verify metrics, filtering, reference copy, and receipt download.
- Complete an approval workflow in `/applications/workspace/{sessionId}` and verify immediate post-submission confirmation screen.
- Verify production build compiles cleanly without warnings.
