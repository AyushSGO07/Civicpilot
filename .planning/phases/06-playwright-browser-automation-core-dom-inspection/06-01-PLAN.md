# Plan 06-01: Build Asynchronous Playwright Browser Manager and Lifecycle Cleanup

## Objective
Establish the backend browser automation runtime using Playwright Chromium (`playwright.async_api`). Implement context pooling per session, desktop viewport configuration, screenshot capture, and strict process lifecycle cleanup to guarantee zero zombie processes.

## Step-by-Step Implementation

### Step 1: Create Agent & Browser Pydantic Schemas
File: `backend/app/models/agent.py`
- Define:
  - `BrowserSessionStatus = Literal["idle", "navigating", "inspecting", "filling", "waiting_approval", "closed", "error"]`
  - `BrowserSessionInfo`: `session_id`, `status`, `current_url`, `page_title`, `created_at`, `updated_at`
  - `BrowserNavigateRequest`: `url: str`, `wait_until: Optional[str] = "domcontentloaded"`, `timeout_ms: int = 30000`
  - `BrowserNavigateResponse`: `session_id`, `url`, `page_title`, `status_code: int`, `screenshot_base64: Optional[str]`

### Step 2: Implement `BrowserSessionManager`
File: `backend/app/services/browser_manager.py`
- Create singleton `BrowserSessionManager`:
  - `initialize()`: Initializes `async_playwright()` and launches Chromium browser (`headless=True`, configurable via env).
  - `create_session(session_id: Optional[str] = None) -> str`: Creates an isolated `BrowserContext` with viewport 1280x800 and desktop user-agent, creates a `Page`, registers in `_active_sessions` dictionary.
  - `navigate(session_id: str, url: str) -> BrowserNavigateResponse`: Navigates page to target URL, waits for network/DOM load, captures screenshot as Base64 string.
  - `get_page(session_id: str) -> Optional[Page]`: Returns active Playwright Page for the session.
  - `close_session(session_id: str) -> bool`: Cleanly closes `Page`, `BrowserContext`, and removes from registry (AGENT-07).
  - `shutdown()`: Iterates through all active contexts, closes them, closes `browser`, and stops Playwright runtime.
  - Integrate lifespan hook in `backend/app/main.py` to invoke `shutdown()` during application shutdown.

### Step 3: Implement Initial Tests in `backend/tests/test_agent_browser.py`
- Test session creation and isolated page context.
- Test navigation and screenshot generation.
- Test clean session termination and registry cleanup (verifying zero zombie processes).

## Verification
- Run `pytest backend/tests/test_agent_browser.py -v`.
- Verify Chromium launches, navigates, and terminates cleanly.
