# Plan 06-02: Implement Semantic DOM Inspection Engine and Agent Browser API Endpoints

## Objective
Build the semantic DOM inspection engine that extracts a clean, accessible tree of interactive form elements from bloated portal HTML, associating labels and generating Playwright locators. Expose FastAPI endpoints for browser session management and DOM inspection.

## Step-by-Step Implementation

### Step 1: Create `DOMInspector` Service
File: `backend/app/services/dom_inspector.py`
- Methods:
  - `inspect_page(page: Page) -> SanitizedDOMTree`:
    - Evaluates the page DOM structure using Playwright page evaluation and BeautifulSoup preprocessing.
    - Filters out non-interactive noise (inline scripts, SVG defs, analytics beacons, display:none hidden containers).
    - Extracts all form-bearing interactive nodes:
      - `<input>` (text, email, tel, number, date, radio, checkbox, file, password)
      - `<select>` (with all `<option>` values and visible labels)
      - `<textarea>`
      - `<button>` and `<input type="submit|button">`
    - Resolves associated labels via:
      - `<label for="...">`
      - Enclosing `<label>` tags
      - `aria-label` or `aria-labelledby`
      - `placeholder` attributes
    - Generates suggested Playwright locators for Phase 7 dynamic mapping:
      - By ID: `#elementId`
      - By Role: `getByRole('button', { name: 'Submit' })`
      - By Label: `getByLabel('Full Name')`
      - By Name: `input[name='fullName']`
    - Returns structured `SanitizedDOMTree`.

### Step 2: Implement FastAPI Agent Router
File: `backend/app/routers/agent.py`
- Endpoints:
  - `POST /api/agent/browser/session/start`: Initializes a new browser session, returns `session_id`.
  - `POST /api/agent/browser/session/{session_id}/navigate`: Navigates to given URL, returns `BrowserNavigateResponse` with screenshot buffer.
  - `GET /api/agent/browser/session/{session_id}/inspect`: Runs `DOMInspector.inspect_page()` on current page, returns `SanitizedDOMTree`.
  - `POST /api/agent/browser/session/{session_id}/close`: Closes the session and cleans up resources (AGENT-07).

### Step 3: Mount Router in `backend/app/main.py`
- Mount `agent.router` at `/api/agent`.
- Register lifespan shutdown hook to invoke `browser_manager.shutdown()`.

### Step 4: Expand Pytest Suite in `backend/tests/test_agent_browser.py`
- Test DOM extraction with sample HTML forms containing text fields, selects, checkboxes, and buttons.
- Verify label association and locator synthesis.
- Verify noise pruning (script tags and hidden elements omitted).
- Test all `/api/agent/browser/...` endpoints with valid and invalid session IDs.
