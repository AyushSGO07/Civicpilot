# Plan 07-02: Implement Playwright Form Action Executor and Agent Form Endpoints

## Objective
Build the asynchronous Playwright form action executor that iterates through `FormFillPlan` actions, autonomously populating text inputs, selecting dropdown options, toggling checkboxes, and attaching Document Vault files on the active browser page. Expose FastAPI endpoints for planning and executing form filling.

## Step-by-Step Implementation

### Step 1: Implement `FormActionExecutor`
File: `backend/app/services/form_executor.py`
- Method `execute_plan(page: Page, session_id: str, plan: FormFillPlan, vault_dir: Optional[str] = None) -> FormExecutionResult`:
  - Iterates through `plan.actions`:
    - `fill_text`: Locates element via `target_locator` (or fallback `input[name="..."]`), calls `locator.fill(value)` with realistic typing cadence.
    - `select_option`: Calls `locator.select_option(value)` or `select_option(label=value)`.
    - `check_box`: Calls `locator.set_checked(bool)`.
    - `select_radio`: Calls `locator.check()`.
    - `upload_file`: Resolves file path from vault, calls `locator.set_input_files(file_path)` (AGENT-05).
    - `click_element`: Calls `locator.click()`.
  - Records execution duration, status (`success` or `failed`), and error message in `ActionExecutionAudit`.
  - Captures post-fill screenshot buffer.
  - Returns `FormExecutionResult`.

### Step 2: Implement FastAPI Form Endpoints in `agent.py`
File: `backend/app/routers/agent.py`
- Add routes:
  - `POST /session/{session_id}/form/plan`: Inspects active page DOM, retrieves citizen profile, generates and returns `FormFillPlan` (AGENT-03).
  - `POST /session/{session_id}/form/execute`: Accepts `FormFillPlan`, executes actions on the active session's page, returns `FormExecutionResult` (AGENT-04, AGENT-05).
  - `POST /session/{session_id}/form/fill`: One-shot endpoint combining inspect -> plan -> execute, returning final execution results and screenshot.

### Step 3: Expand Pytest Suite in `test_agent_form_filling.py`
- Test full browser interaction:
  - Load HTML form into Playwright page.
  - Execute fill plan.
  - Verify inputs have new values (`input_value()`), selects have chosen options, checkboxes are checked.
  - Test file attachment on file inputs.
  - Test API endpoints `/plan`, `/execute`, and `/fill` via httpx ASGI client.

## Verification

- Run complete test suite `pytest backend/tests/ -v`.
- All tests pass, proving autonomous form population on real browser sessions.
