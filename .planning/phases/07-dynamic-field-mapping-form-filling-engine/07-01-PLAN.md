# Plan 07-01: Develop Gemini Dynamic Field Mapping Service and Action Schemas

## Objective
Implement the dynamic field mapping service using Gemini 2.5 Flash (`google-genai` SDK) with deterministic semantic fallback heuristics. Maps citizen profile fields and vault documents to sanitized DOM tree elements without hardcoded CSS selectors, producing structured `FormFillPlan` action sequences.

## Step-by-Step Implementation

### Step 1: Create Form Filling & Action Schemas
File: `backend/app/models/form_filling.py`
- Define:
  - `FieldActionType = Literal["fill_text", "select_option", "check_box", "select_radio", "upload_file", "click_element"]`
  - `FieldAction`: `action_type`, `target_locator`, `element_name`, `field_label`, `value`, `source_attribute`, `confidence`, `reasoning`
  - `FormFillPlan`: `actions: List[FieldAction]`, `unmapped_elements: List[str]`, `missing_mandatory_fields: List[str]`, `generated_at`
  - `ActionExecutionAudit`: `action_index`, `action_type`, `target_locator`, `field_label`, `value`, `status`, `duration_ms`, `error_message`
  - `FormExecutionResult`: `session_id`, `total_actions`, `successful_actions`, `failed_actions`, `action_results`, `screenshot_base64`, `completed_at`

### Step 2: Implement `DynamicFieldMapper`
File: `backend/app/services/field_mapper.py`
- Method `generate_fill_plan(dom_tree: SanitizedDOMTree, profile: CitizenProfileBase, vault_documents: Optional[List[dict]] = None) -> FormFillPlan`:
  - When `GEMINI_API_KEY` is present:
    - Feeds sanitized DOM interactive elements, profile JSON, and vault document catalog to `gemini-2.5-flash`.
    - Uses `response_mime_type="application/json"` and `response_schema=FormFillPlan`.
  - When `GEMINI_API_KEY` is not present (or fallback):
    - Uses deterministic semantic synonym matcher:
      - Maps names, dates, phone numbers, state, district, pincode, income, caste category, occupation.
      - Matches `<select>` options by finding matching state or category value from `DOMElementNode.options`.
      - Matches file upload elements (`type="file"`) to available documents in citizen's vault (`Aadhaar Card`, `Income Certificate`, `Marksheet`).
    - Produces fully structured `FormFillPlan`.

### Step 3: Implement Initial Tests
File: `backend/tests/test_agent_form_filling.py`
- Test semantic mapping for text inputs, numbers, and dates.
- Test `<select>` option matching against option labels and values.
- Test file upload attachment resolution from vault documents.

## Verification
- Run `pytest backend/tests/test_agent_form_filling.py -v`.
- Verify accurate field mapping with zero hardcoded CSS selectors.
